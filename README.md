# QTC-MMS

Official code repository for the study:

**A Language Model–Enhanced Multimodal Framework for Management-Oriented Stratification of Thyroid Nodules**

QTC-MMS (Quiescent Thyroid Cancer Multimodal Management Stratification Model) is a language model–enhanced multimodal framework for management-oriented stratification of thyroid nodules.

## Overview

QTC-MMS integrates:

- Ultrasound ROI images
- Structured clinical variables
- Radiomics features
- Language model–derived semantic representations

The model adopts a hierarchical decision architecture for:

1. Benign–malignant discrimination
2. QTC versus non-QTC stratification among malignant thyroid nodules

## Repository contents

This repository will contain code for:

- Image preprocessing
- Radiomics feature processing
- Multimodal feature fusion
- QTC-MMS model construction
- Model training and inference
- Performance evaluation
- Prognostic analysis
- Transcriptomic analysis

## Data availability

The clinical and imaging datasets used in this study are not publicly available because of patient privacy and institutional data-protection requirements.
